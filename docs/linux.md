# Linux x86-64

Выпуск 0.1.0 содержит AppImage и tar.gz с одинаковым набором: VK Fast, GTK 3/WebKitGTK 4.1, клиентские модули PipeWire и минимальный аудиодекодер FFmpeg. База сборки — Ubuntu 24.04; требуется glibc 2.39 или новее и работающий PipeWire. Графические драйверы используются из системы.

```sh
chmod +x VK-Fast-0.1.0-linux-x86_64.AppImage
./VK-Fast-0.1.0-linux-x86_64.AppImage
```

Если FUSE недоступен, AppImage поддерживает `--appimage-extract-and-run`. Вариант tar.gz запускается без FUSE:

```sh
tar -xzf VK-Fast-0.1.0-linux-x86_64.tar.gz
./VK-Fast-0.1.0-linux-x86_64/AppRun
```

Оба варианта используют обычные XDG-каталоги VK Fast для настроек и кэшей; личные данные в сборку не включаются. Для других письменностей используются шрифты системы. FFmpeg находится внутри пакета и выбирается через его окружение запуска.

## Сборка пакетов

Нужны зависимости сборки из README, Python 3.11+, curl, make, patch, tar/xz/bzip2, patchelf, librsvg2 и GObject Introspection. Клиентские конфигурация и модули PipeWire должны быть установлены вместе с библиотекой. Используйте Ubuntu 24.04 либо эквивалентную базу, чтобы не повышать требование к glibc до версии системы сборки.

```sh
cargo install tauri-cli --version 2.12.4 --locked
VK_FAST_OUTPUT="$PWD/dist" ./scripts/build-linux.sh
```

Tauri CLI используется для упаковки существующего Rust-приложения. Его промежуточные изменения Cargo-манифеста остаются в отдельной рабочей папке. Основной интерфейс VK Fast остаётся egui, скрытый вход обслуживает Tauri.

`scripts/build-ffmpeg-linux.sh` собирает только необходимые аудиодекодеры и протоколы, использует Mbed TLS 3.6.7 с закреплёнными корнями Mozilla и переиспользует готовый Linux-декодер. Windows-декодер при этом не меняется. `scripts/package-linux.py` формирует AppImage и tar.gz, добавляет сведения о компонентах и сохраняет клиентские пути PipeWire внутри пакета.

Исходники, версии компонентов и уведомления доступны через [документацию лицензий](licensing.md). GitHub Release содержит четыре готовые сборки без дополнительных архивов исходников.
