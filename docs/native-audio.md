# Аудиотракт

Декодирование выполняется Symphonia 0.6, преобразование частоты — Rubato 5. Транспорт HLS, извлечение аудио из MPEG-TS и сетевой ввод реализованы на Rust. Встроенный декодер работает в потоке приложения.

Поддерживаются MP3/MPEG Audio, AAC-LC/ADTS, MP4/M4A, FLAC, Ogg/Vorbis и WAV/PCM; HLS принимает аудиоплейлисты, MPEG-TS и fragmented MP4. AES-128 сегментов обрабатывается по ключу и IV из плейлиста. HTTPS-запросы используют Rustls; сессия VK и её cookies в загрузчик медиа не передаются.

Преобразование в 48 кГц stereo f32 выполняется на producer-потоке. Mono дублируется, многоканальный звук сводится по позициям каналов. Sinc-ресемплинг учитывает задержку фильтра. При перемотке декодируется предварительный участок; задержка кодера и временные метки учитываются до выдачи PCM.

Существующий PCM-кэш совместим: 48 кГц, стерео, f32 little-endian. Предварительная загрузка сохраняет весь трек, а перемотка по готовым диапазонам использует кэш. Лимит кэша и очистка прерывают только соответствующие операции.

Нормализации громкости нет: VK не передаёт данных о громкости треков, у его файлов нет тегов ReplayGain/R128, а измерение на лету меняло уровень посреди трека. Выход применяет только громкость пользователя.

PipeWire и WASAPI остаются системными аудиовыходами. Callback читает только подготовленные сэмплы: без декодирования, сетевых запросов, выделений памяти и mutex. Отмена чтения HTTPS прерывает ожидание ответа; остановка не ждёт полного сетевого таймаута.

Тесты используют собственные синтетические аудиофайлы и локальный HTTP-сервер: проверяются форматы, HLS/AES-128, перемотка, отмена и работа кэша. Личные аудиозаписи и сессии в тестах не используются.
