# Лицензии VK Fast

Собственный код распространяется по **GPL-3.0-only**; полный текст — [LICENSE](../LICENSE). Встроенный шрифт Inter — SIL OFL 1.1: [исходное уведомление](../assets/fonts/OFL.txt).

| Компонент | Лицензия |
| --- | --- |
| Symphonia | MPL-2.0 |
| Rubato | MIT / Apache-2.0 |
| Остальные Rust-зависимости | Условия, закреплённые в Cargo.lock и исходных уведомлениях |
| NSIS, инструмент Windows-установщика | [COPYING](third-party/windows/NSIS.txt) |

[Windows-уведомления](third-party/windows/Rust-notices.txt) и [Linux-уведомления](third-party/linux/Rust-notices.txt) содержат лицензии, авторские сведения и ссылки на соответствующие версии библиотек. Их формирует `scripts/collect-licenses.py` по платформенному графу Cargo.lock.

Linux-пакеты используют PipeWire, fontconfig и графические библиотеки из дистрибутива. В AppImage уведомления о самом инструменте упаковки и Rust-компонентах находятся в `usr/share/doc/vk-fast/LICENSES.txt.gz`.

Соответствующие исходники, локальные патчи и рецепты сборки доступны в репозитории и исторических тегах. При распространении сохраняйте доступ к ним и обязательные уведомления. Лицензия VK Fast не заменяет условия сторонних компонентов.
