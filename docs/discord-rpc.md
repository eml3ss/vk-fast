# Discord Rich Presence

Запустите настольный Discord. RPC включён по умолчанию; тумблер находится в
**Настройки → Общие → Discord Rich Presence** и сохраняет выбор между запусками.
Отображение активности также должно быть разрешено в настройках Discord.

При воспроизведении передаются название трека, исполнители, обложка и время.
Название трека открывает трек в VK; обложка ведёт на альбом. Исполнитель
отображается обычным текстом.
Ссылки содержат только публичные адреса страниц, без ключей доступа и аудиопотоков.
Кликабельность появляется после фонового подтверждения объекта в VK. Для
отсутствующего или ещё не проверенного трека/альбома ссылка не добавляется.
Проверки кэшируются; сетевой сбой не считается подтверждением удаления.
На паузе активность полностью скрывается и возвращается после продолжения
воспроизведения. При остановке, выходе из аккаунта,
выключении RPC и завершении плеера активность очищается. Обновления продолжают
работать в трее. Клиент переподключается, если Discord запускается позже или
перезапускается.

Кнопка **GitHub** открывает только репозиторий приложения:
**https://github.com/eml3ss/vk-fast**. Discord скрывает эти кнопки при просмотре
собственной активности; они предназначены для других пользователей.

## Конфигурация сборки

Публичный Application ID приложения **VK Fast** — `1565752977157922916`.
Он включён через `VK_FAST_DISCORD_APPLICATION_ID` в `.cargo/config.toml` и общий
для распространяемых сборок. Пользователям не нужно создавать приложения или
ботов, получать токены и проходить OAuth.

Интеграция использует локальные Unix-сокеты на Linux и named pipes на Windows.
Сетевого RPC-сервера нет; ввод-вывод, повторы подключения и обработка пакетов
выполняются фоновым потоком. Поддерживаются обычные пути IPC и пути Discord
в Flatpak. Версия Discord в браузере локальный IPC не предоставляет.

## Проверки

```sh
cargo test --locked discord
```

Тесты используют синтетические треки и временные IPC-серверы: проверяют
handshake, кнопки, временные метки, паузу, очистку, переподключение, ограничения
размера пакетов и частоты обновлений. Настоящие профили Discord и VK не меняются.

Контракт: [официальная документация RPC](https://docs.discord.com/developers/topics/rpc),
[настройка Rich Presence](https://docs.discord.com/developers/discord-social-sdk/development-guides/setting-rich-presence).
