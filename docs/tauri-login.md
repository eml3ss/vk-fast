# Вход в собственном окне Tauri

Основной вход VK Fast запускается кнопкой **«Войти через VK»**. Официальная страница VK открывается в отдельном окне Tauri 2 с собственным профилем приложения. Профили обычных браузеров, их cookies, история и пароли не читаются. Функции импорта браузерных данных в проекте нет.

## Запуск и завершение

1. Обычный запуск VK Fast открывает основное окно и пробует восстановить сохранённую вебсессию.
2. Если нужен вход, пользователь нажимает кнопку. Сам запуск приложения не открывает окно Tauri.
3. Открывается обычная главная страница `https://vk.ru/`: сайт сам подготавливает вход VK ID после ввода телефона или почты. Прямой запрос VK ID с принудительным возвратом в ленту больше не используется. Доступность пароля и обязательных подтверждений определяет VK. У окна нет общего таймера ожидания.
4. Окно показывается один раз и остаётся на месте во время переходов VK. Возможная лента закрывается экраном «Подключаем VK…» внутри webview. Начальная форма и дополнительные проверки доступны пользователю. Cookies, включая HttpOnly, проверяются нативным API по событиям загрузки и каждые 100 мс.
5. После подтверждения профиля окно скрывается и закрывается один раз. Загрузка музыки выполняется основным приложением. Ошибки и повторные проверки больше не скрывают и не показывают системное окно; устаревшие ответы не принимаются. После сохранения сессии следующий запуск использует готовый вход.

Закрытие окна входа или отмена в VK Fast завершает попытку. Отдельные HTTP-запросы по-прежнему имеют ограниченное время ожидания; отсутствие общего таймера входа не отключает сетевые таймауты. Запуск `vk-fast --login` — явное указание сразу открыть вход; обычный ярлык этот аргумент не передаёт.

## Процессы и границы доступа

Основное окно остаётся egui. Tauri запускается отдельным процессом того же исполняемого файла в служебном режиме `--web-login`, чтобы цикл GTK/WebKit не конфликтовал с циклом egui. Родительский процесс получает результат по приватному каналу; данные сессии не передаются в аргументах или обычных логах.

Вебстраница не получает нативных команд Tauri; глобальный Tauri API выключен, разрешения для окна входа пустые. Переходы окна ограничены HTTPS-страницами VK. Cookies извлекаются нативным API из собственного профиля webview для корневых доменов VK, а не через JavaScript `document.cookie`.

Небольшой скрипт, запускаемый до отрисовки документа, управляет только экраном ожидания. Он не читает поля формы, cookies или браузерное хранилище и не предоставляет странице доступ к Rust-командам.

Основному потоку не нужны локальный TCP-порт, sudo, собственный сервер или регистрация callback-адреса у пользователя. Настройки GitHub Pages и собственного OAuth-приложения не используются этой кнопкой.

## Хранение и выход

На Linux пути начинаются с `$XDG_STATE_HOME/vk-fast`, если XDG-переменная содержит абсолютный путь; иначе — с `~/.local/state/vk-fast`. На Windows эти данные находятся в `config` рядом с `.exe`.

| Путь | Назначение |
| --- | --- |
| `webview/` | Собственный профиль webview, каталог 0700 |
| `webview/.login.lock` | Блокировка одновременного входа и очистки профиля |
| `music-session.json` | Профиль пользователя и собственные cookies VK, файл 0600 в каталоге 0700 |

«Выйти» удаляет сохранённую сессию и очищает собственный профиль webview под блокировкой. Файл блокировки остаётся, чтобы параллельный процесс не обошёл очистку созданием нового lock-файла. При ошибке очистки приложение сообщает об этом. Сессии и профиль обычных браузеров не изменяются.

Профиль webview и файл сессии содержат данные входа и не предназначены для публикации. Аудиокэш находится отдельно в пользовательском каталоге кэша и не содержит cookies, токенов или URL.

## Сборка

В проекте используются `tauri 2.12` с `wry` и `tauri-build 2`. Ресурсы `webview-assets` статические; `build.rs` вызывает `tauri-build`. Для обычного `cargo build --locked` не нужны Node.js, npm или установленный Tauri CLI.

Linux-webview требует GTK 3 и WebKitGTK 4.1. На Arch пакеты называются `gtk3` и `webkit2gtk-4.1`, на Debian/Ubuntu — `libgtk-3-dev` и `libwebkit2gtk-4.1-dev`. Нативные библиотеки обнаруживаются через `pkg-config`; зависимости окна и плеера приведены в [README](../README.md#что-установить). Требования webview сверены с [официальной инструкцией Tauri](https://v2.tauri.app/start/prerequisites/#linux).

## Другие способы входа

QR — отдельная кнопка с подтверждением на телефоне и ограниченным VK сроком действия самого QR. Он также создаёт собственную вебсессию приложения.

Старый VK ID OAuth доступен разработчику через `--oauth-login`: внешний системный браузер, PKCE, GitHub Pages и native callback `vkfast://`. Это отдельный механизм, который не запускается основной кнопкой. Опубликованная страница callback сохраняется; её наличие не означает, что Tauri-вход использует браузер или этот сайт.
