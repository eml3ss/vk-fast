# Windows x86-64

Выпуск содержит установщик NSIS и portable-архив для Windows 10+ x86-64 (MSVC). Вывод звука — WASAPI через CPAL; системный микшер Windows преобразует 48 кГц float PCM под устройство.

Установщик работает для текущего пользователя. По умолчанию приложение устанавливается в `%LOCALAPPDATA%\Programs\VK Fast`; можно выбрать другую доступную для записи папку. Создаётся ярлык в меню «Пуск», ярлык на рабочем столе можно отключить.

Настройки и кэш выбираются независимо:

| Вариант | Настройки | Кэш |
| --- | --- | --- |
| AppData (по умолчанию в установщике) | `%LOCALAPPDATA%\VK Fast\config` | `%LOCALAPPDATA%\VK Fast\cache` |
| Папка установки | `<папка приложения>\config` | `<папка приложения>\cache` |

Выбор записывается в `vk-fast-storage.ini` рядом с `.exe` и сохраняется при повторной установке в ту же папку. Если файла нет, приложение использует portable-режим. Рабочий каталог процесса на пути не влияет. Существующие данные в выбранных папках сохраняются; при смене расположения автоматического переноса нет. Перед обновлением нужно полностью закрыть плеер, включая трей. Деинсталлятор удаляет файлы программы и ярлыки, сохраняя настройки и кэши.

Portable-архив содержит только `vk-fast.exe` в корне. Поместите его в доступную для записи папку и запустите: каталоги настроек и кэша создаются автоматически. Состав создаваемых папок данных в обоих вариантах:

| Папка | Содержимое |
| --- | --- |
| `config` | настройки, вход VK, история, последний трек и позиция |
| `cache/audio` | аудио, отдельный лимит до 5 ГиБ |
| `cache/library`, `cache/covers`, `cache/avatars` | данные библиотеки и маленькие изображения |


Папка приложения должна быть доступна для записи. Вход выполняется по QR-коду, отдельные компоненты Windows вроде WebView2 не нужны. Обычные профили браузеров приложение не читает.

Размер, положение окна и развёрнутое состояние сохраняются в `config/window.json` при закрытии, в том числе в трей. Если монитор отключён, окно возвращается в пределы доступного экрана.


Декодирование и обработка звука встроены в `vk-fast.exe` и выполняются на Rust. Текущий архив содержит один исполняемый файл. Для перехода с 0.1.x один раз установите актуальную версию вручную поверх прежней, сохранив config/cache. Далее обновления продолжают работать из приложения.

## Обновления

Начиная с 0.1.1 Windows-версия проверяет стабильные GitHub Releases после запуска и затем раз в шесть часов. При новой версии слева от настроек появляется кнопка с номером версии; она открывает описание и загрузку. В **Настройки → О приложении** есть ручная проверка и тумблер автоматической проверки, включённый по умолчанию.

После загрузки нажмите **Установить и перезапустить**. Плеер сохранит состояние и полностью завершится, включая трей; отдельный процесс заменит `vk-fast.exe` и откроет приложение снова. Сессия, настройки, кэши, расположение данных, ярлыки и деинсталлятор сохраняются. Обновление подходит и portable, и установленной версии; папка приложения должна быть доступна для записи. При ошибке замены или запуска восстанавливаются предыдущие файлы.

Загрузка идёт только из `eml3ss/vk-fast` по HTTPS, размер и SHA-256 сверяются с GitHub API. Архив извлекается по списку разрешённых файлов во временную папку, без записи пользовательских данных. Предварительные выпуски и понижение версии исключены. Проверка не использует VK-сессию и не требует GitHub-токена.

В 0.1.0 механизма обновления ещё нет: один раз установите актуальную версию вручную. Установщик можно запустить поверх прежней установки; portable — распаковать в прежнюю папку после полного закрытия плеера, сохранив существующие `config`/`cache`.

## Сборка на Linux

Для основного приложения нужны официальный Rust 1.95+ с целью `x86_64-pc-windows-msvc`, Cargo, LLVM (`clang-cl`, `lld-link`, `llvm-lib`, `llvm-rc`), Python 3.11+ и [cargo-xwin](https://github.com/rust-cross/cargo-xwin) для загрузки MSVC CRT/Windows SDK. Используйте компилятор и стандартную библиотеку из одного официального toolchain.


Для NSIS на Linux нужен Wine. `scripts/windows_installer.py` скачивает NSIS 3.13 из официального выпуска и проверяет закреплённые SHA-256. Компилятор хранится в `~/.cache/vk-fast-build-tools`, запускается в собственном Wine-префиксе и не использует обычный профиль Wine. Пути можно переопределить через `VK_FAST_BUILD_TOOLS` и `VK_FAST_NSIS_WINEPREFIX`.

Пример подготовки с rustup:

```sh
rustup toolchain install stable --profile minimal --target x86_64-pc-windows-msvc
cargo install --locked cargo-xwin --version 0.23.1
export XWIN_ARCH=x86_64
export XWIN_CACHE_DIR="$HOME/.cache/vk-fast-xwin"
cargo xwin cache xwin
export VK_FAST_XWIN_ROOT="$XWIN_CACHE_DIR/xwin"
rustup run stable ./scripts/build-windows.sh --installer --output dist
```

`scripts/windows-msvc.py` передаёт Cargo точные пути CRT/SDK и использует статический MSVC runtime. Он также работает, когда парсер конфигурации конкретной версии cargo-xwin несовместим с установленным Cargo. Если SDK уже подготовлен, повторно скачивать его не нужно. `VK_FAST_WINDOWS_SYSROOT` позволяет указать отдельный официальный Rust sysroot; `RUSTC`/`PATH` при этом должны выбирать соответствующий официальный компилятор.

Результат с `--installer`:

- `VK-Fast-0.3.0-windows-x86_64-setup.exe` — установщик с выбором папок, ярлыками и деинсталлятором.
- `VK-Fast-0.3.0-windows-x86_64.zip` — только `vk-fast.exe` в корне; папки данных создаются при запуске.


Для автоматической установки поддерживаются `/S`, `/CONFIG=appdata|portable`, `/CACHE=appdata|portable` и стандартный NSIS `/D=`. Последний параметр задаётся в конце командной строки без кавычек, даже если путь содержит пробелы:

```bat
VK-Fast-0.1.0-windows-x86_64-setup.exe /S /CONFIG=appdata /CACHE=portable /D=D:\Apps\VK Fast
```

`vk-fast.exe --print-data-paths` печатает выбранные пути без запуска интерфейса и чтения сессии VK.
